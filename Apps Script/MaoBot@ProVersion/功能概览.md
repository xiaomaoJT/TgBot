## 一、这是什么

MaoBot 是一个跑在 **Google Apps Script（GAS）** 上的 Telegram 机器人。ProVersion 是在官方版 `MaoBot@OfficialVersion`（V1.74）基础上做的**结构性重构**：

- 修掉了真正会让功能失效的 Bug（入群检测、回调转圈、关键字串分支、缓存失效、超长消息丢失等 18 处）；
- 淘汰了一批已下线的第三方接口，换成**多源故障转移**；
- 把 Telegram 官方 Bot API（9.4 ~ 10.3）能力真正用起来（60+ 个方法）；
- 在上层补了三块新能力：**富消息 / 临时消息**、**多模型 AI**、**频道监听与关键词推送**；
- 并铺好了**热更新**链路（配置热更新 / 在线覆盖 / 本地 clasp / CI 自动部署）。

官方版目录**完整保留、未改动**，两个版本可并存、可随时回滚。

**当前规模**：15 个模块（含 Secrets.gs）· 约 11566 行 · 365 项本地冒烟测试全绿 · 510 处顶层声明 0 重复。

## 二、本次更新要点（最近一轮）

这一轮主要解决三件事：**双语**、**Webhook 稳定性**、**可以放心开源**。

### 1. 🌐 中英文切换（i18n）
- 支持**按聊独立**切换中文 / 英文，**不调用任何翻译接口**（英文是代码里预置的静态文案，不把聊天内容发给第三方）。
- 私聊任何人都能 `/lang en` / `/lang zh` 切自己的语言；群聊只有管理员 / Bot 主人能改（防滥用），改的是「这个群」的语言。
- 语言按聊持久化（缓存 24h + `chat_settings` 表），切完本条之后即生效。未提供英文的地方自动回落中文，不会空白。

### 2. 🐞 Webhook 302 真因根治 + 自愈闭环
- **根因**：GAS 的 `/exec` 对 POST 请求架构上永远返回 302 到 `…/macros/echo`，Telegram 严格不跟随重定向 → 判投递失败，表现为「时灵时不灵 / 首条能回后续全哑」。与权限无关。
- **解法**：`doPost` 返回值从 `ContentService` 换成 `HtmlService.createHtmlOutput(...)`，GAS 直接回 200、不再重定向。
- **自愈**：`pollUpdates()` 探测到 Webhook 已绑就自动让位（避免抢消息 / 刷 409）；`runDailyMaintenance()` 里加 `ensureReachable()`，发现 Webhook 又 302 且无轮询 → 自动清积压 + 装轮询；新增 `/mode` 手动切 `polling` / `webhook`。

### 3. 🔐 密钥外移 Secrets.gs（可安全开源）
- 真实密钥从 `Modules/Params.gs` 移到 `Modules/Secrets.gs`（被 `.gitignore` 排除），`Params.gs` 只保留空占位，**可安全提交到公开仓库**。
- 别人 clone 后：`cp Modules/Secrets.gs.example Modules/Secrets.gs` 填自己的值即可。
- `keep-remote-values.js` 的空值保护已跳过这 6 个外移密钥，push 时不会再把手填的真值写回 `Params.gs`。

## 三、功能全景

### 📋 指令体系
| 分类 | 代表指令 |
|:-----|:---------|
| 基础 | `/start` `/help` `/menu` `/id` `/ping` `/lang` |
| 查询 | `/weather` `/hot` `/ai` `/ip` `/phone` |
| 娱乐 | `/hitokoto` `/dujitang` `/qinghua` `/fortune` `/dice` `/coin` `/roll` |
| 工具 | `/calc` `/tr` `/short` `/qr` `/img` `/t` `/file` |
| 群组 | `/info` `/stat` `/top` `/rules` `/report` |
| AI（填密钥即生效） | `/ai` 多轮对话 · `/sum` 摘要 · `/ask` 提问 · `/code` 写码排错 · `/polish` 润色 · `/see` 看图 · `/digest` 群聊总结 · `/todo` 待办 · `/models` 模型与额度 |
| 群管 | `/manage` `/ban` `/mute` `/kick` `/warn` `/pin` `/purge` `/invite` `/settings` `/broadcast` |
| 频道 | `/ch`（列表）`add` `del` `key` `on` `off` `test` `log` |
| 维护（仅主人） | `/health` `/webhook` `/sync` `/reload` `/word` `/push` |

### ⭐ 富消息 + 临时消息（观感升级）
- **富消息**：一份「块结构」数据同时产出 GFM 与 HTML 两份产物，`/hot` `/top` `/stat` `/health` `/models` `/ch log` 用上**真表格 / 标题 / 列表 / 折叠块**；富消息不可用时自动降级 HTML，两条路径永不脱节。
- **临时消息**：`/id` `/ping` `/calc` `/ip` `/t` `/file` `/phone` `/ai` 这类「答案只对本人有意义」的回复走 `ephemeral_message_parameters`，**群里其他人看不见**，不需要「先发再定时删」。含「富+临时 → HTML+临时 → 公开+定时删」三级降级。

### 🧠 AI 能力层（AI.gs）
- **12 家免费模型**注册表（Gemini / Groq / Cerebras / Mistral / OpenRouter / GitHub Models / Together / Cloudflare 等 + 自定义兼容端点），填了密钥自动生效。
- **故障转移**：主模型 429 / 超时 / 报错自动切下一个，用户无感；`/models` 看当前顺序与今日用量。
- **配额保护**：按模型分别计数，免费额度烧光前先拒绝，不把 429 甩给用户。
- **隐私默认**：免密钥的 Pollinations 默认不进转移链（否则内容会被静默发给未配置的第三方），要显式打开。
- **工作类任务**：摘要 / 提问 / 写码 / 润色 / 看图 / 群聊总结 / 待办提取。

### 📡 频道监听 · 查询 · 关键词推送（Channel.gs）
- 机器人是频道管理员时，新帖进处理管线；`/ch log` 按时间倒序查历史（带分页）。
- 按 **频道 × 关键词 × 目标会话** 配置规则，命中即图文原样转发（`copyMessage`）。规则写错也不会把自己刷爆（单帖最多推 5 个目标）。
- 推送卡片标明「为什么推给我」（命中了哪些关键词），并带「查看原帖」「暂停监听」按钮。

### 🎛 群管与自动化
- 敏感词过滤（DFA + 缓存，绝杀词即封即删，敏感词 3 次自动封禁）；反刷屏（阈值 / 禁言 / 踢出）。
- 入群按钮验证（防广告机器人）；警告系统（累计 3 次自动移出）。
- 群级功能开关面板（写入 `chat_settings`，每个群独立）；每日维护（清任务队列 / 日志 / 过期警告）。
- 触发器从「20 个一次性触发器」收敛为「1 个调度器 + `task_queue` 任务队列」，解除 20 触发器硬限制。

### 🔗 热更新（四条路）
| 改了什么 | 用什么 | 代价 |
|:---------|:-------|:-----|
| 开关 / 关键词 / 敏感词 / 群规 | Telegram 里发 `/reload` | 零 |
| `Modules/` 下的 `.gs` 代码 | `bash Tools/push.sh --deploy` | 一条命令 |
| 没装 Node / 装不上 npm | `node Tools/bundle.js` 合并单文件后粘贴一次 | 一次粘贴 |
| 提交即自动上线 | 仓库根 `GitHub Actions` | 配一次 Secret（`CLASPRC_JSON`） |

## 四、架构与工程质量

- **15 个模块**按固定顺序拼装（顺序由 `Tools/modules.js` 的 `ORDER` 唯一决定，`build.js` 与 `bundle.js` 共用，杜绝顺序漂移）：
  `Params → Secrets → Utils → Core → I18n → Telegram → UI → Api → AI → Channel → Deploy → Commands → Manage → Triggers → MaoBot`。
- **本地测试**（`bash Tests/run.sh`）：模拟 GAS 运行时，**不联网、不耗配额**，365 项冒烟测试覆盖指令链路、敏感词、权限、回调翻页、幂等、富消息降级、临时消息三级降级、AI 故障转移、频道推送、热更新等关键路径。
- **`check-dupes.js`**：GAS 所有 `.gs` 共享扁平全局作用域，同名顶层函数会静默覆盖 —— 这个检查把「重复声明」变成构建期硬失败（510 处声明，0 重复）。
- **`verify-push.js`**：push 后把线上代码拉回来逐字节比，避免「推了却没生效」。

## 五、开源与安全说明

- 真实密钥集中在 `Modules/Secrets.gs`（被 `.gitignore` 排除），**绝不进仓库**；`Params.gs` 只留空占位，可安全提交。
- 仓库内**不要提交**的文件已在 `.gitignore` 写死：`Modules/Secrets.gs`、`.clasp.json`、`dist/`、`dist-bundle/`、`node_modules/`、`.DS_Store`。
- 可安全提交的对应模板：`.clasp.json.example`、`.claspignore`、`Modules/Secrets.gs.example`。
- `/calc` 用**手写递归下降解析器**（字符白名单校验），不使用 `eval`；外链按钮自动过滤空值；群成员隐私数据不落表。

## 六、快速开始

```text
① 复制 Modules 下全部 .gs + appsscript.json 到你的 GAS 项目
② 复制 Modules/Secrets.gs.example → Modules/Secrets.gs，填 EXECID / BOTID / KingId / botIdAlone / geminiKey / webappUrl
③ 运行 initDatabase() → onBotInit()（自动建表 → 自检 → 注册命令菜单 → 装调度器 → 绑 Webhook）
```

详细步骤见 **[COURSE.md](./COURSE.md)**；部署排错与能力路线图见 **[README.md](./README.md)** 与 **[ROADMAP.md](./ROADMAP.md)**。

> 📌 **边界（诚实告知）**：GAS 适合日均 3,000 条以内的社群；无法做 SSE 真流式输出（已用「思考中」草稿气泡替代）；运行时读不到自身源码（`/push` 只比对版本号）。大群建议迁 Cloudflare Workers / VPS。
